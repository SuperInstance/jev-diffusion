How It Works

1

JEV Plans

JEV (Joint Embedding Validator) makes schema-constrained decisions about regions, mood, palette, and lighting. With composite-JEV enabled, Qwen + DeepSeek also vote.

{
  "regions": "sky",
  "mood": "serene",
  "palette": "warm",
  "lighting": 1.0
}
2

Substrate Segments

The image is decomposed into substrate cells based on the preset. Each cell is a node with cell_id, region, prev_hash.

cell-00: sky
  prev_hash: 0x0000000000000000
cell-01: horizon
  prev_hash: 0x8e1c57a40ce4ec80
cell-02: midground
  prev_hash: 0x45af13f2542f834b
3

LLMs Render

Each cell is rendered by an LLM (Qwen for even, DeepSeek for odd, or routed by composite-JEV). The LLM sees the plan, its neighbors, and the target.

[Qwen renders cell-00 sky]
"deep celestial vault awash in cool indigo..."
4

Critic Iterates

A GAN-like critic scores the combined result on completeness, specificity, coherence, and composition. High scores stop the loop; low scores trigger another iteration.

{
  "completeness": 9.5,
  "specificity": 9.0,
  "coherence": 9.5,
  "composition": 9.0
}
5

Unify

DeepSeek assembles the cells into a single 4-6 sentence description. This is the final output — a refined text description that could be passed to any image generator.

API

You can run this from the command line or via HTTP. Both work without any setup beyond API keys.

CLI

python3 jev_diffusion.py "your target" --preset landscape --iterations 3

Python

from jev_diffusion import JevDiffusion
d = JevDiffusion(target="...", preset="landscape", iterations=3)
result = d.run()
print(result['combined'])
