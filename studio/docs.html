The Doctrine

JEV-Diffusion is a method for generating rich image descriptions using substrate segmentation and LLM-as-GAN. It produces no actual images — it produces descriptions that could be fed to any image generator (Stable Diffusion, DALL-E, Midjourney).

Why description, not image?

  • Observable: every cell has a hash, every iteration is logged
  • Composable: cells chain via prev_hash, can be shared
  • Editable: edit any cell, the rest survives (no-deletion)
  • Cheap: runs on $0.10 of LLM tokens vs $5 of GPU
  • Iterative: GAN-like critic loop refines quality

The 5 stages

  1. JEV Plans — schema-constrained decisions on regions, mood, palette, lighting
  2. Substrate Segments — image becomes a graph of cells
  3. LLMs Render — each cell gets a 3-5 sentence description
  4. Critic Iterates — multi-dimension scoring, refine until quality threshold
  5. Unify — DeepSeek assembles cells into 4-6 sentence description

The Cell

Each cell in the substrate is an irreducible unit with its own identity. The cell carries:

{
  "cell_id": "cell-02",
  "region": "midground",
  "position": [2, 0],
  "prev_hash": "0x45af13f2542f834b",
  "hash": "0xc898e7e814b8e650",
  "jev_decision": {},
  "llm_render": "A solitary figure wrapped in a tattered, deep indigo cloak...",
  "critic_score": 9.5,
  "metadata": {
    "preset": "landscape",
    "backend": "qwen",
    "rendered_at": 1790063203.586021
  }
}

The cell has its own hash, its own decision history, and links to its parent via prev_hash. This is the substrate cell doctrine in operational form.

Presets

Presets define canonical region layouts for different image types:

landscape

  • sky (region 0)
  • horizon (region 1)
  • midground (region 2)
  • foreground (region 3)

portrait

  • background, head, shoulders, hands, accent

abstract

  • 4 free-floating compositions

still_life

  • background, tabletop, primary_object, secondary_object, accent

sci_fi

  • environment, structure, vessel, lighting, particle

Composite JEV

When use_composite_jev=True, the system uses multiple models to vote on JEV's plan:

# JEV's primary answer
jev_ans = jev.plan(target, questions)

# Other models vote
votes = {qwen: ..., deepseek: ...}

# Use the agreed-upon answer
final = agreement(jev_ans, votes)

This adds robustness. JEV is schema-constrained (can't hallucinate), but composite voting ensures the answer isn't an outlier.

Tradeoff: ~3x slower (extra model calls) but more reliable.

Critic Loop

The critic scores the combined cell descriptions on 4 dimensions:

  • completeness (0-10): Does it cover all aspects of the target?
  • specificity (0-10): Is it vivid and concrete?
  • coherence (0-10): Do cells connect smoothly?
  • composition (0-10): Strong visual composition?

If average ≥ 9.0, the loop stops early. Otherwise, it iterates up to N times.

GAN-like behavior

JEV-Diffusion is GAN-like in that there's a generator (cell renderers) and a discriminator (critic). Unlike a true GAN, both are LLMs and there's no gradient. But the loop has the same shape: generate, evaluate, refine.

Extensions

JEV-Diffusion is a primitive that composes with other substrate doctrines:

Cross-paradigm mitosis (text_diffusion)

Each cell can be a mitosis root. When the description is >1500 tokens, the cell divides into 2 daughters with prev_hash → parent.

Motif agents (motif_quilt)

cell-explorer can find similar past diffusions. cell-reviewer can audit quality. cell-tester can verify hashes.

Composite JEV (composite_jev)

The critic itself can be a composite — multiple models vote on whether to continue.

Wavefunction JEV (composite_jev_v2)

Each cell is a measurement of a quantum substrate. Critics compute Bell-state interference.

Substrate canon

Every diffusion run creates cells in the substrate worker. They're queryable, traceable, and composable with other cells.
